🎮 Modo Interactivo

Ejecute las pruebas con una interfaz visual para seleccionar y monitorear las pruebas.

💡 Recomendado para principiantes
Este modo le permite ver cada paso y interactuar con las pruebas en tiempo real.

📝 Instrucciones:

  1. Se abrirá Playwright UI en una nueva ventana del navegador
  2. Verá una lista de todas las pruebas disponibles organizadas por archivos
  3. Puede seleccionar pruebas específicas o ejecutar todas
  4. Use los filtros para buscar pruebas por nombre o tags
  5. Haga clic en ▶️ para ejecutar las pruebas seleccionadas
  6. Vea los resultados, capturas de pantalla y videos en tiempo real

  • Videos: Grabaciones de las ejecuciones fallidas
  • Trace Files: Archivos de traza para debugging profundo
  • JSON Reports: Datos estructurados para análisis
